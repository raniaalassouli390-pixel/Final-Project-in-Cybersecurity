Reverse Tabnabbing

What it is

When a page opens a link with target="_blank", the new page can reach the old one through window.opener and change its address. An attacker uses this to swap your real tab for a fake login page while you read the new tab. OWASP: A01 Broken Access Control. CWE-1022.

Why it matters

You trust the first tab because it was already open and logged in. After the swap it looks like your site asks you to sign in again, so people type their password into the attacker's page. This is phishing that needs no hacking of your server. Modern browsers now treat _blank links as noopener by default, but old browsers, old code and window.open calls still need the fix.
